Descripción

UTN-OS es un proyecto de sistema operativo desarrollado con fines educativos y experimentales.

El objetivo principal es explorar, implementar y documentar diferentes conceptos relacionados con el funcionamiento interno de un sistema operativo, desde el proceso de arranque hasta los componentes de bajo nivel.

El proyecto se encuentra actualmente en desarrollo.

Objetivos

- Comprender el funcionamiento interno de un sistema operativo.
- Experimentar con programación de bajo nivel.
- Estudiar el proceso de arranque de un sistema.
- Investigar la interacción entre hardware y software.
- Implementar progresivamente componentes fundamentales de un sistema operativo.
- Documentar el proceso de desarrollo y los conceptos aprendidos.

El proyecto está orientado al desarrollo de software de bajo nivel y al estudio de arquitectura de computadores y sistemas operativos.

Las tecnologías utilizadas pueden variar durante el desarrollo.

Estado del proyecto

En desarrollo

Actualmente el proyecto se encuentra en una etapa temprana de desarrollo. Se irán incorporando nuevas funcionalidades y documentación conforme avance el proyecto.

Roadmap

- [ ] Documentar la arquitectura del sistema.
- [ ] Definir el proceso de boot.
- [ ] Implementar el núcleo inicial.

Instalación y desarrollo

Clonar el repositorio:

git clone https://github.com/DaiGeass/UTN-OS.git
cd UTN-OS

Consulta la documentación dentro de "docs/" para conocer el estado actual del proyecto y los procedimientos de desarrollo.

Documentación

La documentación técnica del proyecto se encuentra dentro del directorio:

docs/

En este directorio se irá registrando información relacionada con la arquitectura, desarrollo, decisiones técnicas y funcionamiento interno de UTN-OS.

Aviso

UTN-OS es un proyecto experimental y educativo. No está diseñado para utilizarse como sistema operativo de producción.
